# YWS Energia Solar — Calculadora Solar

Calculadora preliminar para dimensionamento de sistemas fotovoltaicos, com estimativas baseadas em:

- Valor mensal da conta de energia;
- Consumo mensal em kWh;
- Área útil disponível no telhado.

## Como usar

Abra `index.html` em um navegador. Escolha o modo de cálculo, informe os dados solicitados e consulte a estimativa de quantidade de módulos, potência instalada, geração e investimento.

## Publicar no GitHub e na Vercel

1. Envie `index.html` e `README.md` para a raiz do repositório GitHub.
2. Na Vercel, importe o repositório.
3. Para esta versão estática, normalmente não é necessário configurar framework, comando de build ou diretório de saída.
4. Faça o deploy e use o endereço gerado pela Vercel.

## Observação importante

Os resultados são estimativas iniciais, não substituem visita técnica, análise de sombreamento, orientação e inclinação do telhado, regras da concessionária, tarifa aplicável e validação do projeto elétrico. Valores de geração e custos devem ser ajustados à realidade local antes de apresentar uma proposta comercial.

# YWS Energia Solar — Simulador Fotovoltaico

Calculadora estática em HTML, CSS e JavaScript, com visual responsivo para celular e computador.

## Funcionalidades
- Três modos de cálculo: valor da conta, consumo mensal em kWh e área útil do telhado.
- Estimativa de potência instalada, quantidade de módulos, área, geração mensal, investimento de referência e economia bruta.
- Parâmetros ajustáveis para tarifa, horas de sol, perdas, potência/área dos módulos e custo por kWp.
- Atualização dos resultados durante a edição dos campos.
- Botão para copiar o resumo da simulação.
- Não depende de bibliotecas ou serviços externos.

## Como testar
1. Abra `index.html` em um navegador moderno.
2. Escolha um modo de cálculo e informe os dados.
3. Ajuste os parâmetros conforme a realidade do projeto.
4. Use **Copiar resumo da simulação** para copiar os resultados.

## Publicar na Vercel
1. Envie `index.html` e `README.md` para a raiz do repositório.
2. Importe o repositório na Vercel.
3. Escolha o tipo de projeto estático/Other. Não é necessário comando de build.
4. Faça o deploy.

## Importante
Os resultados são estimativas preliminares e não substituem visita técnica, análise de sombreamento, orientação e inclinação do telhado, avaliação estrutural, regras da distribuidora, tarifa aplicável ou projeto elétrico. O investimento e a economia devem ser ajustados à realidade local antes de apresentar uma proposta comercial.
